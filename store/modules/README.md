# STORE MODULES

This directory contains your Vuex Store Module files.

All the modules are required to have a '.store.js' extension to be pickedup dynamically.

**Make sure the filename is exactly what you want to import.
e.g. - if you want to import auth store and use it as 'Auth/yourgetter' or '\$store.Auth.commit' the filename should be 'Auth.store.js'**
